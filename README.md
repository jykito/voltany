# Voltany

Voltany is a standalone Botania addon for Minecraft 1.20.1 (Forge). It adds an FE-to-Mana generator and automated versions of Botania's hand-operated crafting stations.

Downloads and the full description are on CurseForge:
https://www.curseforge.com/minecraft/mc-mods/voltany

## Dependencies

- Minecraft 1.20.1, Forge 47.x
- Botania (required)
- Patchouli and Curios (required by Botania)

## Building

Standard ForgeGradle. From the project root:

    ./gradlew build

The built jar is placed in `build/libs/`.
